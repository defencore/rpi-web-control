Set up GStreamer and the receiver connection

Connect the receiving computer by Ethernet or Wi-Fi. Allow incoming UDP from the Pi on the receiver port you chose.

Windows

On the GStreamer download page, open Windows and choose MSVC x86_64 for an Intel or AMD PC, or MSVC arm64 for Windows on Arm. Run the installer and select “Only runtime”.

Open a new Command Prompt. If it cannot find gst-launch-1.0, add the installed folder containing gst-launch-1.0.exe to your user Path, then reopen Command Prompt. A default per-user x64 install uses %LOCALAPPDATA%\Programs\gstreamer\1.0\msvc_x86_64\bin.

Linux

On a Debian or Ubuntu desktop, run these commands in Terminal. For another distribution, see the Linux installation guide.

sudo apt update
sudo apt install gstreamer1.0-tools gstreamer1.0-plugins-base gstreamer1.0-plugins-good gstreamer1.0-gl gstreamer1.0-x
macOS

In Terminal, use Homebrew to install GStreamer. If you are installing Homebrew first, follow its “Next steps” to enable the brew command.

brew install gstreamer
Verify the installation

Run each line in Command Prompt or Terminal. The first prints the version. The next two display information about the RTP/JPEG receiver and JPEG decoder. The last opens a short test pattern on the receiving display.

gst-launch-1.0 --version
gst-inspect-1.0 rtpjpegdepay
gst-inspect-1.0 jpegdec
gst-launch-1.0 videotestsrc num-buffers=90 ! videoconvert ! autovideosink

With Homebrew Python on a Mac, create and activate an export environment in that folder.

              
python3 -m venv .export-venv
source .export-venv/bin/activate

            
Before the first export, install Pillow in the Python environment you will use to run the converter.

              
python3 -m pip install Pillow

            
Run this command in that folder using your ZIP filename. By default, the video follows the camera’s sensor timestamps.

              
python3 render_recording.py recording.zip output.mp4
